## Featured project

### [applestylepitch](https://github.com/flllmedianewyork-collab/applestylepitch)

A Chinese proposal Skill that connects brief analysis, slide copy, campaign roadmaps, and Apple-inspired editable presentations.

```text
Brief → Outline → Materials → Confirmed copy → Visual production → Verification
```

- **Content first:** explain the reasoning, evidence, conditions, and next steps.
- **Practical planning:** choose project execution, annual timeline, or channel roadmap formats.
- **Consistent design:** configurable colors, typography, spacing, and editable slide objects.
- **Clear boundaries:** distinguish facts, estimates, and examples; review each actual deliverable.

I defined the workflow, proposal requirements, Chinese writing standards, and visual review criteria. Implementation was AI-assisted, and adapted third-party methods are credited in the repository.
